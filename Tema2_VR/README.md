# VR Target Game

Proiect VR realizat în Unity 6 folosind OpenXR și XR Interaction Toolkit.

## Funcționalități

- XR Device Simulator pentru testare fără headset
- Grab și aruncare a obiectelor
- Cuțit aruncabil
- Țintă pentru lovituri
- Scor afișat pe ecran
- Scor calculat în funcție de distanța dintre punctul de impact și centrul țintei
- Cu cât lovitura este mai aproape de centru, cu atât punctajul este mai mare
- La lovirea țintei, panoul scorului își schimbă culoarea timp de 5 secunde ca efect vizual

## Tehnologii

- Unity 6
- OpenXR
- XR Interaction Toolkit
- C#
